# 澳门威尼斯人非官方 3D 互动导览 V0.5.2

这是用户自制、非官方的互动导览页面。页面保留 33 条官方来源样本，并展示 14 张经用户授权公开发布的御匾会自摄照片。

## 使用边界

- 本项目与澳门威尼斯人、金沙中国、御匾会 / Paiza Club 及相关权利人无隶属、合作或认可关系。
- 相关名称和商标归各自权利人所有。
- 3D 场景是功能区示意，不提供精确导航、步行距离或实时交通指引。
- 御匾会的会籍、邀请、接待和使用资格以官方当前安排为准，不代表公众可自由进入。
- 照片反映一次现场体验；菜品、价格、营业时间和供应情况可能变化，以官方及现场为准。
- 官方资料核验日期：2026-11-08；公开发布准备日期：2026-11-09。

打开 `index.html` 即可运行。页面为单文件静态应用，不需要服务器端组件、付费服务或用户数据收集。
